# 检查点：深层 Markdown 标题与表格可访问性（phase-156）

- 日期：2026-11-28
- 合入版本：v0.180.0
- 目标：面板渲染器只支持 `#`–`###`。模型生成的卡片/Wiki 常用 `####`
  划分子小节，此前会以字面 `#### 标题` 的段落出现，阅读层级断裂；
  表格表头也缺少 `scope`，屏幕阅读器无法建立列关联。
- 状态：代码、测试、双语文档与检查点更新；待全量门禁与提交。

## 交付

- `client.js`：
  - 标题识别从 `#{1,3}` 扩展到 `#{1,6}`；仍按“页面 h1 由外层容器承担”
    映射为 `h2`–`h6`，`Math.min(level + 1, 6)` 钳制，避免生成非法 `h7`；
  - 深层标题沿用 `anchorOf` 生成唯一锚点 id；
  - 段落与表格行的块级中断正则同步扩展到 `#{1,6}`，`####` 不再被吸进
    上一段；
  - 表格 `th` 增加 `scope="col"`。
- 测试：客户端夹具卡片新增 `#### 四级标题` 小节；DOM 用例断言 `h5`
  节点、锚点 id、表头 `scope` 属性。

## 语义边界

- 标题层级仍是“Markdown 级 +1”：`#` → `h2`，`####` → `h5`，`#####`/
  `######` → `h6`（钳制）；页面真实 h1 由外层标题承担，避免重复。
- 自动目录（wiki 渲染侧）仍只收录 `##`/`###` 章节，深层标题只保证排版与
  锚点，不改变目录结构。
- 表格可访问性只加 `scope="col"`，不引入 `caption`（生成内容无标题字段，
  不虚构）。
