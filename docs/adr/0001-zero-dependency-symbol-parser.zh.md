# ADR-0001：符号提取采用零依赖轻量解析器，不用 外部解析框架

- 日期：2026-11-25
- 状态：已采纳（Phase 1）

## 背景

方案评审修订版（§6.3）设计 index-service 用 外部解析框架 WASM 在宿主进程做
AST 解析。但 §8.3 把"外部解析框架 WASM 在 Electron 宿主的加载与体积"列为
未验证项；vendoring 各语言 grammar 还引入网络下载与逐个许可证审查。用户
已批准"零依赖解析器"路线（Phase 1 计划确认）。

## 选项

- **A. 零依赖手写解析器**：行级关键字匹配 + 括号/缩进块匹配，覆盖
  JS/TS/Python 主流定义形态。
- **B. 外部解析框架 WASM（vendored）**：精确解析，但需原型验证 Electron
  宿主加载、管理 grammar 二进制资源与许可证。

## 最终选择

选项 A。

## 理由

1. 消除方案明列的最大技术风险（WASM 在 Electron 宿主未验证）。
2. bundle 维持零 npm 运行时依赖、零 vendored 二进制，本地目录安装即可跑。
3. 对"符号表 + 交叉引用"目标，轻量解析在主流语言上精度足够；32 个单元
   测试覆盖函数/类/方法/接口/类型/导入的核心形态。
4. 解析层是独立模块（src/symbols.js、src/deps.js），未来若验证 外部解析框架
   可行，替换解析层而不动工具/资产契约。

## 影响范围与局限（诚实披露）

- 装饰器、JSX 块、TypeScript 参数属性等边缘语法的覆盖有限；解析失败时
  安静跳过，绝不产出错误符号（保证索引可用性优先于覆盖率）。
- `endLine` 为保守估计（括号配平/缩进），非精确 AST 边界；Phase 3 的
  变更传导按"文件级为主、符号级引用表辅助"设计，不依赖精确 endLine。

## 回滚方案

删除 src/symbols.js 与 src/deps.js，以 外部解析框架 实现同名导出
（extractSymbols/extractImports 签名不变），测试随之更新。
